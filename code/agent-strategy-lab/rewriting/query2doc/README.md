# Query2doc

- 준비일: 2026-11-08.
- 상태: **폴더·역할 문서만 준비됨. 구현·프롬프트·테스트·실험 결과 없음.**
- 목적: 생성한 가상 문서로 검색 질의의 표현을 확장.
- 구현 범주: B: 생성 프롬프트 + 검색 연결.
- 입출력·상태 설계 대상: 원질의·가상 문서·확장 질의·실제 검색 결과.
- [분야 색인](../README.md), [상세 용어집](../../../../text/agent-strategy-lab/01-design/chapter-00-glossary.md).

## 내부 디렉터리

| 경로 | 향후 책임 |
|---|---|
| `prompts/` | 직접 작성할 역할별 프롬프트·예시와 버전. 현재 내용 없음 |
| `examples/` | 개별 방법의 실행 예제. 현재 실행 파일 없음 |
| `tests/unit/` | 실제 모델 없이 계약·분기·상태·종료를 확인할 테스트 |
| `tests/live/` | 실제 모델·도구를 쓰는 검증. 호출 비용·실행 조건을 명시할 대상 |

향후 알고리즘은 이 방법의 `strategy.py`, 방법별 데이터 계약은 `contracts.py`에서 설계할 후보이며 이번에는 생성하지 않았다. 단일 호출 방법은 불필요한 상태 구조를 추가하지 않는다.

## 검증 목표

원질의 기준선, 검색 품질, 의도 손상, 가상 문서를 실제 근거로 오인하는지 확인. 코드 검증과 실제 성능 비교를 구분하고 공통 비교는 `experiments/`·`evaluation/`에서 수행한다. 프롬프트 버전·모델·입력·도구·한도를 기록해 비교한다.

- 위 역할은 기존 조사에 근거한 구현 준비안이다. 이번 단계에서 원논문 코드 감사·재현이나 새 성능 검증은 하지 않았다.
