# 00. ARMAP 용어와 해석 경계

| 용어 | 쉬운 뜻·예시 |
|---|---|
| ARMAP | 자동 합성 자료로 보상 모델을 학습하고 계획·탐색을 돕는 방법 |
| RM / reward head | Reward Model, 행동 경로의 목표 일치도를 평가하는 모델 / 은닉 상태를 숫자로 바꾸는 출력층 |
| preference pair | 같은 과업의 두 경로 중 어느 쪽이 더 나은지 표시한 학습 쌍 |
| BCE / logit | 두 후보의 점수 차이로 선호를 학습하는 이진 교차 엔트로피 / 확률 변환 전 점수. 실제 성공률이 아님 |
| VILA / LoRA | 시각·언어 모델 계열 / 작은 추가 행렬로 일부 가중치를 미세조정하는 방식 |
| Best-of-N / B | N개 경로를 만든 뒤 보상 모델 점수가 가장 높은 것을 선택 |
| Reflexion / R | 과거 실행 피드백을 언어적 반성으로 다음 시도에 사용 |
| MCTS / UCT / M | 후보 가지를 반복 선택·확장·평가·역전파하는 탐색 / 성과와 탐색량을 균형 있게 고르는 규칙 |
| reward_pd / reward_gt | 학습된 모델의 예측 점수 / 실제 환경 성과. 같은 숫자 범위나 의미를 보장하지 않음 |
| sample avg / max / sel | 생성 경로 평균 실제 성과 / 실제 정답을 안다고 가정한 최대 성과 / 모델 점수로 고른 경로의 실제 성과 |
| reset / rollout | 과거 환경 상태로 복원 / 후보에서 종료까지 경로를 진행해 평가 |

학습 라벨용 실제 성과, 선택용 모델 점수, 최종 독립 평가를 구분한다. 코드 읽기와 실제 학습/실행 검증도 구분한다. 날짜 2026-11-15, 고정 커밋 `411ad9dd7baaa6f66d31e416cd100214447bd5f3`.
