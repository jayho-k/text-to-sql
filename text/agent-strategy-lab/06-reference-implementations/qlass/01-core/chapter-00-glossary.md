# 00. QLASS 용어와 확인 범위

| 용어 | 쉬운 뜻·예시 |
|---|---|
| QLASS | Q값으로 언어 에이전트의 다음 행동 후보를 선택하는 학습·탐색 방법 |
| Q-value / QNet | 특정 상태에서 행동 후 기대하는 장기 보상 / 이를 예측하는 모델. 최종 정답 자체가 아님 |
| SFT | 정답 예시를 모방하는 지도 미세조정. 여기서는 정책 학습과 QNet 회귀 학습을 나눠 봄 |
| TreeNode / trajectory | 상태·행동·보상·자식을 담은 탐색 노드 / 연속된 행동·관측 기록 |
| terminal / finished | 환경 실행이 종료된 상태. 성공 여부·실제 보상과 별도 필드로 확인해야 함 |
| reset / replay | 같은 과업을 초기화한 뒤 선택한 과거 행동을 다시 실행해 후보 분기를 만드는 것 |
| best_of_N / n_trajs | 단계마다 평가할 행동 후보 수 / 같은 과업에서 생성할 전체 경로 수. 서로 다른 예산 |
| ICL | 모델 입력에 소수의 시연을 넣는 문맥 내 학습. 가중치 학습과 다름 |
| MSE | 예측 Q값과 라벨의 차이를 제곱해 줄이는 회귀 손실 |
| dev / test | 이 저장소 ALFWorld에서는 분포 내 140개 / 분포 밖 134개 과업에 대응 |
| sparse checkout / commit | 필요한 코드 경로만 로컬에 가져오는 기능 / 소스의 고정 버전을 식별하는 해시 |

분석일 2026-11-15. 실제 환경·가중치·데이터를 실행/로드하지 않은 정적 소스 분석이다. 원문 N37과 현재 공개 커밋이 실험 당시 코드와 동일하다는 보장은 미확인이다. 코드 자체의 프롬프트는 외부 원본 파일로 보존하며 논문 부록과 같은 출처로 합치지 않는다.
